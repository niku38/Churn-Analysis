# Telecom Customer Churn Analysis

## 📌 Objective
Analyze customer churn behavior to identify why long-tenured, non-senior customers are leaving and recommend strategies to improve retention.

## 🛠️ Tools & Technologies
- Python (Pandas, Seaborn, Matplotlib)
- SQL (data querying and filtering)
- Power BI (dashboard visualization)
- Statistical tests (Chi-Square)

## 📂 Project Highlights
- Queried and filtered telecom customer data using SQL to explore churn trends
- Analyzed churn behavior of long-tenured, non-senior customers using Python
- Applied Chi-Square tests to find relationships between churn and key features
- Built Power BI dashboards to visualize churn patterns, payment types, and contract risks
- Discovered 42.6% churn rate among customers using electronic checks
- Identified monthly contracts and lack of services (like tech support) as churn factors

## 💡 Recommendations
- Promote auto-payment options like credit cards or bank transfers
- Encourage long-term contracts with retention benefits
- Improve customer support and service add-ons

## 📈 Impact
Enabled business teams to take data-backed decisions on contract design, service offerings, and payment methods to reduce churn.
